# The Smack Tracker — v1.0

A buprenorphine dose tracker and taper planner that runs entirely in your browser.

- No account, no ads, no data collection.
- Your dose history and settings are stored only on your own device (browser local storage). Nothing is uploaded.
- Use **export json** to back up your history and **import json** to restore it or move it to another device.
- Optional: the **photo import** tab can read handwritten dose notes. It sends the photo to Anthropic's Claude using your own Anthropic API key, which is saved only in your browser.

## Use it

Open `index.html` in any modern browser, or visit the GitHub Pages link for this repository.

## Not medical advice

This is a personal tracking and planning tool. Your decisions are your own, to be made with a licensed physician. Read the disclaimers page in the app before using it.
